# Architecture

Native EDA files → existing read-only adapters → CanonicalIrBundle → EngineeringGraph → Anchor/Pin Group → HardwareBlock Candidate → Human Review → Published API.

PDF → same asset inventory → PDF.js text/page coordinates → pdfEvidence. It does not enter logical nets until a future connectivity reconstruction adapter has been independently validated.

Vercel hosts Next.js and short authenticated storage APIs. Browser handles individual input parsing. scripts/batch-mine.ts executes isolated sequential jobs on a local host/server and retains source bytes. PostgreSQL stores normalized bundles, immutable mining runs, editable block snapshots and audit events. There is no LLM dependency or automatic paid processing.
