# 多格式报告修复 — Parser 1.5.1

本批修复：

- 跨文档 pin→pad 按 partId 匹配，避免多单元/重复位号遍历别的器件引脚。封装匹配优先明确映射、同目录唯一候选，禁止 Map 最后写入覆盖。重复的同类型有向链接合并 evidence；名称匹配有多个候选时不猜测。
- KiCad 同名工程根节点及层级子页闭包；历史/自动保存/未引用设计保留在源清单，标记不参与 IR。多个入口返回选择提示（本版通过单独上传目录选择，尚无交互式工程选择器）。
- EasyEDA SOLIDREGION 与 COPPERAREA 字段拆分；几何路径不能进入网络名。缺失 docType 时按记录证据分类，歧义则报错而非默认为原理图。
- Altium 工程依赖缺失提示；ActiveBOM 专属保留诊断；识别的结构级文件不再叠加通用“不支持”提示。
- S-expression 改为惰性 token 迭代，避免同时存完整 token 数组和 AST。保留资源限制；PCB 超限包含文件名、字节数、限制和处理建议。尚不是按 section 增量生成 IR，未声称解决全部大型 PCB。
- 页脚读取实际解析器版本，部分失败/部分解析不再显示 Validated bundle。网络名增加跨格式不变量检查。

新增合成回归覆盖活动文档、多入口、SOLIDREGION、旧 PCB 类型检测、歧义拒绝、AD 依赖、BOM、链接重复发现和 tokenizer 边界。

未完成验收：测试报告的 85 个原始工程尚未提供；嘉立创 Pro 5 个重复 ID 工程、KiCad 重复实例/9/10 网表差异需要实际失败记录定位。层级实例展开、完整流式 PCB 构建、AD 库目录/3D/覆铜、按域精细完整度仍待后续实现。本批不删除冲突实体来伪造 0 error。
